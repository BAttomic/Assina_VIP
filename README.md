# Assina_VIP

Loja online de assinaturas digitais, jogos e produtos. Next.js 16 + React 19 + TypeScript, deploy no Dokploy em `assinavip.battomic.com`.

```bash
npm ci
npm run dev
```

Toda a documentação, incluindo padrões de código, arquitetura, deploy e pendências, está em [docs/](docs/README.md).
